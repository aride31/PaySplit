# PaySplit

PaySplit is a simple, mobile-first web app for instantly splitting a bill evenly across a group. It is designed for speed: enter a total, add names, and get per-person amounts in seconds.

## MVP Features

- Enter total bill amount
- Add/remove people dynamically
- Equal split calculation
- USD currency formatting (dollars/cents)
- Clear validation for invalid totals or empty names
- Reset button to quickly start over
- Copy/share-ready summary text
- No login, backend, or database

## Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` directly in your browser.
